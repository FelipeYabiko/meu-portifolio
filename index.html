FONAR

Flutter Dart FastAPI Firebase Cloud Run

Plataforma de avaliação vocal clínica para fonoaudiólogos, nosso TCC. O app em Flutter, para Android e Windows, guia a consulta inteira: consentimento que bloqueia a gravação, aferição do ruído da sala, gravação em WAV conferida, fila de envio que funciona sem internet, escala CAPE-V, evolução do paciente e laudo em PDF. 02

Mercado

Next.js TypeScript Claude API Firebase Stripe

Vitrine digital do comércio de bairro. Mercadinho, padaria e açougue publicam produto com foto e preço e colam o QR Code na porta. A lista inteligente usa a API do Claude com tool calling: a pessoa descreve o que precisa, o modelo escolhe os itens do catálogo e o servidor busca os preços reais e a loja mais barata — preço nunca sai do modelo. Pagamento com Stripe e app Android com Capacitor.
