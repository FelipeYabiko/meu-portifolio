# Aprendizados

Biblioteca de lições deste projeto: o detalhe de cada erro corrigido e de cada coisa que deu certo. Não leia inteiro:
busque pelo assunto do momento. O que vale para **toda** mudança sobe para `docs/regras-de-ouro.md`; o que dá para
conferir sozinho vira regra em `ferramentas/fiscal/regras-do-projeto.mjs`.

Formato de cada lição: `### assunto · data`, depois **o que aconteceu**, **por quê** e **como fazer daqui em diante**.
